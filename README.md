# Pawmily Vet Clinic

A comprehensive veterinary clinic management system designed to streamline operations and enhance pet care services.

Live Page: https://pawmilyvetclinic.onrender.com/

## Overview

Pawmily Vet Clinic is a full-stack web application built to help veterinary clinics manage appointments, patient records, staff schedules, and medical services efficiently. The platform provides an intuitive interface for both clinic staff and pet owners.

## Features

- **Patient Management**: Track pet profiles, medical history, and vaccination records
- **Appointment Scheduling**: Easy booking system with calendar view
- **Staff Management**: Manage veterinarians, technicians, and support staff
- **Medical Records**: Maintain detailed health records and treatment history
- **User Authentication**: Secure login system for staff and pet owners
- **Responsive Design**: Mobile-friendly interface for on-the-go access

## Technology Stack

- **Frontend**: HTML (44.3%), CSS (19.3%), JavaScript (3.7%)
- **Backend**: Python (32.7%)
- **Architecture**: Web application with HTML/CSS/JavaScript frontend and Python backend

## Getting Started

### Prerequisites

- Python 3.x
- pip (Python package manager)
- Modern web browser

### Installation

1. Clone the repository:
```bash
git clone https://github.com/7zhiqq/PawmilyVetClinic.git
cd PawmilyVetClinic
```

2. Install Python dependencies:
```bash
pip install -r requirements.txt
```

3. Run the application:
```bash
python app.py
```

4. Open your browser and navigate to:
```
http://localhost:5000
```

## Usage

### For Clinic Staff
- Log in with staff credentials
- Manage patient records and appointments
- Schedule staff and resources
- View clinic reports and statistics

### For Pet Owners
- Create and manage pet profiles
- Schedule appointments online
- View appointment history
- Access pet medical records
